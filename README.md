AI PC Diagnosis
================

■ 起動方法

AI_PC_Diagnosis.exe をダブルクリックしてください。


■ 主な機能

・CPU使用率診断
・メモリ使用率診断
・ディスク使用率診断
・CPU温度
・GPU温度
・NVMe SMART
・Windowsイベントログ
・AIによる診断分析
・HTMLレポート
・JSONログ
・過去レポート


■ AI分析について

AI分析を使用する場合はOllamaが必要です。

使用モデル：
gemma4


■ レポート

reportsフォルダーにHTMLレポートが保存されます。


■ ログ

logsフォルダーにJSON診断ログが保存されます。


■ 注意

LibreHardwareMonitorのハードウェア情報取得には
管理者権限が必要になる場合があります。
